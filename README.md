# Keeyaa · Link di Bio

Halaman link di bio Keeyaa Catering & Bakehouse, tayang di **https://sofyandiselayar-gif.github.io/keeyaa/**

## Cara mengubah isi
1. Klik `index.html` → ikon **pensil (Edit)**.
2. Ubah hanya bagian di antara `UBAH DI SINI SAJA` dan `akhir bagian yang diubah`:
   - `kota`, link `tiktok`, `facebook`, `googleMaps`, `gofood`, `grabfood`, `shopeefood` (kosongkan `""` untuk menyembunyikan tombol)
   - `promo` (kosongkan `judul: ""` saat tidak ada promo)
   - `menuHarian` (ganti setiap Senin)
   - `harga`
3. Klik **Commit changes**. Halaman ter-update dalam ±1 menit.

Jaga tanda kutip `"` dan koma `,` tetap ada. Kalau halaman jadi kosong setelah edit, buka **History** untuk kembali ke versi sebelumnya.

## File
- `index.html`: halaman
- `assets/keeyaa-katalog-menu.pdf`: katalog (ganti dengan nama file yang sama saat katalog diperbarui)
- `assets/og-image.jpg`: gambar pratinjau saat link dibagikan
